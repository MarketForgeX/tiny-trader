# Tiny Trader

**Learn. Tap. Trade.** 🎮

Tiny Trader is a simple, colorful web game that introduces young children to basic market ideas through large touch-friendly interactions.

### Concepts
- Buy and sell
- Price going up and down
- Profit and loss
- Patience and waiting
- Virtual coins only

### Run locally
Open `index.html` in a browser.

### GitHub Pages
This is a static website and can be hosted with GitHub Pages.

### Educational note
This is a playful learning experience, not a real trading or investment tool.
